# TradeLink ET — Agent Guide

## Project Overview

Ethiopia-based B2B broker marketplace. The platform is a **silent broker**: neither suppliers nor buyers see that a commission is collected. This is enforced server-side in Convex. Currency is Ethiopian Birr (ETB), locale `"en-ET"`.

## Commands

```bash
npm install
npm run dev              # Vite dev server (port 5173)
npm run convex:dev       # Convex dev (run in separate terminal)
npm run build            # tsc && vite build — NOTE: no tsconfig.json exists yet, this will fail
```

No `lint`, `format`, `test`, or `typecheck` scripts. No CI. No ESLint/Prettier config.

## Required Environment

Copy `.env.example` to `.env.local`. Four vars required:

- `VITE_CONVEX_URL` — Convex deployment URL
- `VITE_CLERK_PUBLISHABLE_KEY` — Clerk client key
- `CLERK_SECRET_KEY` — Clerk server key (Convex-side)
- `CLERK_JWT_ISSUER_DOMAIN` — Clerk JWT issuer domain

Dev requires **two terminals**: `npm run dev` + `npm run convex:dev`.

## Architecture

**Stack**: React 18 + Vite 5, Convex (realtime DB + serverless), Clerk (auth), Tailwind v3, GSAP 3, React Router v6.

**Path aliases** (in `vite.config.ts`):
- `@` → `./src`
- `@convex` → `./convex` — **defined but never used**; all Convex imports use relative paths like `../../convex/_generated/api`. Use `@convex` for new imports to stay consistent with the alias.

**Auth stack** (outermost → innermost): `ClerkProvider` → `ConvexProviderWithClerk` → `BrowserRouter` → `App`. See `src/main.tsx`.

**Route structure** (`src/App.tsx`): three role-scoped route trees — `/importer/*`, `/wholesaler/*`, `/admin/*` — each gated by `RoleRoute`. Many imported page components **do not exist yet** (stubs).

## Critical Business Rules

### Commission (`convex/lib.ts:applyCommission`)

- Looks up category-specific commission rules first, falls back to default rule, then hardcoded **8%**.
- Returns `{ displayPrice, commissionAmount, supplierPayout }`. All rounded to 2 decimal places.
- **`rawPrice` must NEVER leak to wholesalers.** `sanitizeProductForRole()` strips it from wholesaler-facing data and replaces `price` with `displayPrice`.

### Identity Masking (`convex/lib.ts:generateAlias`)

- All cross-party data uses aliases like `"Supplier-A12B"` / `"Buyer-9F3C"` (last 4 chars of user ID).
- Only the admin dashboard reveals real identities and raw revenue figures.

## Conventions

- **Component classes** in `index.css` (`@layer components`): `.card`, `.card-hover`, `.badge`, `.badge-green`, `.badge-gold`, `.badge-gray`, `.badge-red`, `.btn`, `.btn-primary`, `.btn-secondary`, `.btn-outline`, `.btn-gold`, `.input`, `.text-gradient`, `.scrollbar-thin`. Prefer these over raw Tailwind utilities where they match.

- **GSAP animation pattern**: add CSS class `.gsap-reveal` (or `.gsap-reveal-left`, `.gsap-reveal-right`, `.gsap-scale-in`) to elements, then attach `useGsapReveal()` hook ref to the container. Initial hidden styles are in `index.css`. Always clean up with `gsap.context()` + `ctx.revert()`.

- **Conditional classes**: `clsx` is used; `tailwind-merge` is installed but unused. A `cn()` helper combining both is expected but not yet created.

## Schema (7 tables)

`users`, `products`, `commissionRules`, `deals`, `orders`, `messages`, `notifications`, `reviews`. See `convex/schema.ts` for full definitions.

**Key fields**: `products.rawPrice` (private), `deals.agreedRawPrice` / `agreedDisplayPrice` / `commissionAmount`, `orders.supplierPayout` / `commissionEarned` — admin-only fields that must never leak to the wrong role.

**Gap**: `convex/orders.ts` is referenced in the schema but **does not exist yet**.

## Dependencies Not Yet Used

`zustand`, `tailwind-merge`, `react-hook-form`, `zod` — installed but no source file imports them. Intended for future work.

## Known Gaps

- **No `tsconfig.json`** — `npm run build` calls `tsc` but there's no config. Path alias `@` won't resolve in TypeScript without one. This needs to be created before `build` will work.
- **`RoleRoute`** is imported from `@/components/layout/RoleRoute` in App.tsx but actually exported from `ProtectedRoute.tsx`. Needs reconciliation.
- **`{src/` directory** at project root is a filesystem artifact — not a real directory. Ignore it.
- **No `convex/_generated/` in git** — these files are auto-generated by `npx convex dev` or `npx convex deploy`. Do not edit them manually.
